# 🩸 Blood Request Portal

## 📌 Project Overview

The **Blood Request Portal** is a cloud-based web application designed to help people request and find blood donors quickly during emergency situations. The system provides a centralized platform where users can submit blood requests and connect with potential donors.

The project demonstrates how **Cloud Computing** can be used to develop an accessible and scalable healthcare-related application.

## 🎯 Objectives

* Make blood requests easier and faster.
* Connect blood recipients with potential donors.
* Reduce the time required to find suitable blood donors.
* Provide an organized platform for managing blood requests.
* Demonstrate the practical use of cloud computing concepts.

## ⭐ Key Features

* 🩸 Blood request submission
* 👤 Donor and requester information management
* 🔍 Blood group-based searching
* 📋 Request management
* 🌐 Web-based accessibility
* ☁️ Cloud computing integration
* 📱 User-friendly interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Cloud Computing
* GitHub

## 🔄 How It Works

1. A user opens the Blood Request Portal.
2. The user provides the required blood group and request details.
3. The request is submitted through the portal.
4. Available donors can be identified based on the required blood group.
5. The requester can use the available information to contact a suitable donor.

## 💡 Benefits

The Blood Request Portal can help improve communication between blood seekers and donors and can be particularly useful during urgent situations. Similar digital blood-management systems are designed around connecting recipients, donors, hospitals, and blood banks through centralized platforms.
